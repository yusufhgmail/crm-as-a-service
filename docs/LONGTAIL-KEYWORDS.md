# Longtail keyword seed list — dynamic landing system

First working list for the dynamic longtail-keyword landing system (see STRATEGY.md "Marketing" section). Goal: keywords with real search intent, low competition, each mapping to a niche whose landing section the LLM generates on the fly.

## Pattern templates

- "CRM for {niche}"
- "best CRM for {niche}"
- "{niche} CRM software"
- "CRM system for small {niche} business" (SE: "CRM system för {niche}")
- "{tool} alternativ för {niche}" (comparison/switcher intent)

## Swedish niches (primary market, established SMEs, 5-30 customer-facing staff)

Painters (målerifirmor), electricians (elinstallatörer), plumbers (VVS-firmor), carpenters (snickeri), HVAC, cleaning companies (städfirmor), moving companies (flyttfirmor), property managers (fastighetsförvaltare), locksmiths (låssmeder), garden/landscaping (trädgårdsmästare), builders (byggfirmor), window/door installers, roofing (takläggare), chimney sweeps, painters/decorators, auto workshops (bildelar/bilverkstäder), towing (bärgningsfirmor),IT support firms (IT-support företag), accounting firms (redovisningsbyråer), recruitment agencies (rekryteringsbyråer), insurance brokers (försäkringsmäklare), real estate agents (fastighetsmäklare), architects (arkitektkontor), surveyors (mätningstekniker), logistics/freight (speditörer), wholesalers (partihandel).

## Notes
