# AI search visibility: the prompts to track (draft, 4 Nov 2026)

Ubersuggest's AI Search Visibility tracks up to 15 prompts for one brand and reports whether ChatGPT, Perplexity and Gemini name the brand and which page they cite. Saving the brand spends one of the account's monthly brand credits, and the prompt list can only be changed by resending all of it, so the list is approved here first.

The prompts are what a buyer at a 10–50 person US company would type into an assistant. Each one maps to a guide that should be the cited page.

## How to use the results

- Run the brand setup once the site is deployed and the guides are indexed; before that every prompt will return nothing.
- Check monthly. The number to watch is how many of the 15 prompts name CRM From Within at all, then which page is cited.
- A prompt that cites a competitor's page is a brief for improving the matching guide: read the cited page, see what it answers that ours does not.
- Keep the list stable for at least three months so the trend means something.

## The same check, by hand

Until the Ubersuggest brand is set up, ask the 15 prompts in ChatGPT, Perplexity and Gemini on the first of the month and note the answer in a sheet: named / not named, page cited, competitors named. Twenty minutes a month.
