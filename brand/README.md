# Company Native brand kit

This folder is the frozen brand system for Company Native. It contains the editable source files and the ready-to-use exports needed for the website, LinkedIn, X, founder-led outreach, assessments, proposals and the first customer conversations.

## Start here

- `company-native-brand-guide.html` is the editable brand guide.
- `../output/pdf/company-native-brand-guide.pdf` is the shareable guide after generation.
- `BRAND-ITERATIONS.md` records the customer-perspective rounds and why the identity was frozen.
- `assets/logos/` contains the primary, reversed and monochrome logo files.
- `assets/social/` contains profile, banner, open-graph and launch-post files.
- `assets/templates/` contains a one-pager, assessment cover, proposal cover and email signature.
- `assets/web/` contains favicon and app-icon exports.

## Which file to use

- Light background: `logos/company-native-lockup-color.svg`
- Dark background: `logos/company-native-lockup-reverse.svg`
- Small square or avatar: `logos/company-native-mark-dark.svg` or the matching PNG
- One-color production: `logos/company-native-mark-mono.svg`
- Website/social preview: `social/company-native-og-1200x630.png`
- LinkedIn page: `social/linkedin-avatar-400.png` and `social/linkedin-cover-1128x191.png`
- X profile: `social/x-avatar-400.png` and `social/x-header-1500x500.png`

The SVG files are the masters. Use PNG only where the platform does not accept SVG.

## Frozen rules

- Do not create a separate CRM logo or sub-brand.
- Do not replace the Coremark with the old CN monogram.
- Do not use generic AI imagery such as sparkles, brains, circuits or glowing networks.
- Keep coral to actions and the company core. Use Native Ink, not white, for text on coral.
- Keep public language concrete: what we learn, build, migrate, remove and improve.
- Revisit the system only when customer behavior reveals a real problem.
