# CRM From Within brand kit

This folder is the brand system for CRM From Within. It contains the editable source files and the ready-to-use exports needed for the website, social profiles, founder-led outreach, assessments, proposals and the first customer conversations.

## Start here

- `crm-from-within-brand-guide.html` is the editable brand guide.
- `../output/pdf/crm-from-within-brand-guide.pdf` is the shareable guide after generation.
- `BRAND-ITERATIONS.md` records the customer-perspective rounds and why the identity was frozen.
- `assets/logos/` contains the primary, reversed and monochrome logo files.
- `assets/social/` contains profile, banner, open-graph and launch-post files.
- `assets/templates/` contains a one-pager, assessment cover, proposal cover and email signature.
- `assets/web/` contains favicon and app-icon exports.

## Which file to use

- Light background: `logos/crm-from-within-lockup-color.svg`
- Dark background: `logos/crm-from-within-lockup-reverse.svg`
- Small square or avatar: `logos/crm-from-within-mark-dark-1024.svg` or the matching PNG
- One-color production: `logos/crm-from-within-mark-mono.svg`
- Website/social preview: `social/crm-from-within-og-1200x630.png`
- LinkedIn page: `social/linkedin-avatar-400.png` and `social/linkedin-cover-1128x191.png`
- X profile: `social/x-avatar-400.png` and `social/x-header-1500x500.png`

The SVG files are the masters. Use PNG only where the platform does not accept SVG.

## Frozen rules

- Use the same CRM From Within identity for the hands-on service and final self-builder vision.
- Do not replace the Coremark with initials or a literal nested-box symbol.
- Do not use generic AI imagery such as sparkles, brains, circuits or glowing networks.
- Keep coral to actions and the company core. Use Native Ink, not white, for text on coral.
- Keep public language concrete: the CRM begins with how the customer works, is built for them and improves with them. Keep migration secondary.
- Revisit the system only when customer behavior reveals a real problem.
